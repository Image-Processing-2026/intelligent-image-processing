Chưa có ảnh được chọn

Mỗi model nhận ảnh + đúng instruction ở đây. Tự do phân tích và đề xuất, không kèm danh sách tools hoặc prompt từ hệ thống thật.

Một lượt = 3 request ảnh, mỗi model trả một câu trả lời. Kết quả tự lưu trên máy.

Cách so sánh Ảnh + một system prompt, không có lượt lập kế hoạch riêng

Ba model nhận cùng PNG chuẩn hóa và nguyên văn system prompt. Không thêm mục tiêu, nhận xét định sẵn, lịch sử hội thoại, tool schema hoặc kết quả model khác. Mỗi model tự chọn cách phân tích và đề xuất trong cùng một câu trả lời.

Temperature 0.4 · Thinking tắt/tối thiểu · Output vẫn chịu giới hạn token và chính sách API của nhà cung cấp. Groq chờ 65 giây, Gemini chờ 13 giây giữa các lượt để giảm lỗi quota. Chờ này không tính vào thời gian API.
