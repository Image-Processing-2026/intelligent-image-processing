# Frontend Demo Application

This directory contains the user interface for **intelligent-image-processing**.

---

## 1. Quick Start
To launch the interactive Gradio demo interface:

```bash
python frontend/app.py
```

Open your browser at `http://localhost:7860`.

---

## 2. Features
- Drag-and-drop image upload.
- Optional ground-truth image upload (to test synthetic mode with PSNR/SSIM).
- Interactive visual side-by-side comparison (Before / After).
- Real-time display of VLM diagnosis reasoning, region operations, and quality evaluation scores.
